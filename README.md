# IT Work - 学生成绩管理与拼图游戏

## 项目简介
本项目是实验3"项目质量计划与基于Git的配置管理"的代码仓库，包含两个功能模块：
- **拼图游戏**（李阔）：基于Java Swing的4x4拼图游戏
- **学生成绩管理系统**（张子妍）：基于控制台的学生成绩管理应用

## 小组成员
- 李阔
- 张子妍

## 项目结构
```
it-work/
├── src/
│   ├── likuo/
│   │   └── PuzzleGame.java          # 拼图游戏主界面
│   └── zhangziyan/
│       └── StudentGradeManager.java  # 学生成绩管理系统
└── README.md
```

## 代码命名规则
- 包名：使用成员姓名拼音全小写（likuo, zhangziyan）
- 类名：PascalCase（大驼峰命名法）
- 方法名：camelCase（小驼峰命名法）
- 常量：UPPER_SNAKE_CASE（全大写下划线分隔）

## 分支说明
- `main`：主分支，存放稳定版本代码
- `likuo`：李阔的开发分支
- `zhangziyan`：张子妍的开发分支
